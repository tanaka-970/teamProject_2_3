■MMD■
MME(MikuMikuEffect)が導入済みである必要があります。

SakurabaEma_ByPOWER.pmxをMMDへ読み込むとシェーダー(AlternativeFull)が自動反映されます。
AlternativeFullを使用しない場合、テクスチャに灰色の線が出ることがあるのでミップマップOff推奨です。(AlternativeFullが適応されると強制的にミップマップはOffになります。)

【PostAlphaEye】
桜羽エマの作画を表現するために眉毛とまつ毛を髪の手前に表示するようにするためのエフェクトです。原作再現度に差が出るので使用を強くおすすめします。
PostAlphaEye.xを読み込んでください。
※詳細についてはPostAlphaEye/Readme.txtをご覧ください。

【PostAlphaEye_Skirt】
激しい動きをするとスカートの貫通が目立ちます。
PostAlphaEyeエフェクトを使用して擬似的にスカートの貫通をごまかすことができるような設定しているため、クオリティにこだわる方は使用をおすすめします。
ただ読み込むだけだとジャケットに影が落ちなくなってしまうため、使用方法についてはPostAlphaEye_Skirt_Manualフォルダの画像にて説明しております。

【モーフ説明】
・Ey_〇〇
ゲーム本編でのエマの表情を一括で再現できるモーフです(目元のみ)。
・Ex_〇〇
ゲーム本編でのエマの表情を一括で再現できるモーフです。
